## The word

**petrichor** — the scent of rain falling on dry earth.

One word, nine letters, no explanation, no second draft. It is surprising
(a smell most people have felt but never named), vivid and specific (the
first rain after a dry spell), and it carries a spark of sound in it
(`petra`, stone, + `ichor`, the blood of the gods in old Greek myth).

## How it works

`main.ts` (Node 22, standard library only, no network) validates the word
— exactly one word, 1–24 characters — writes it to `/output/entry.txt`,
and verifies the round-trip read matches exactly.

```sh
node main.ts
cat /output/entry.txt   # petrichor
```
